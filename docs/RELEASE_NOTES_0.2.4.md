# BC3 MultiDetails v0.2.4

修复底部共享横向滚动条没有带动全部多行 Text Details 内容的问题。

- 监听 BC3 横向滚动条实际发送消息的外层原生编辑器，并把新的横向位置同步
  到另一侧详情编辑器；滑块拖动、箭头与翻页都会让全部选中行一起移动。
- 跨编辑器同步及恢复原始数据源时，横向位置按目标编辑器的有效范围限制，
  避免长行执行 `End`、选择复制后退出时触发 BC3 原生断言。
- 新增逐编辑器像素同步回归和无异常退出回归。
- 支持从正式 v0.2.0、v0.2.1、v0.2.2 或 v0.2.3 安全原地升级。

已使用两个各 10,000 行的文件，同时选择三条 10,000 字符差异行完成验证：
真实拖动后上下两组共六条详情内容保持同一横向位置；整行复制得到 10,000
字符；随后正常退出且没有异常窗口。

目标版本：Windows Beyond Compare 3.3.5 build 15075。
